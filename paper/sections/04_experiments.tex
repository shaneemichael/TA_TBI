\section{Experiments}
\label{sec:experiments}

\subsection{Implementation}

The experiment is implemented as a Python package with command-line entry points for data preparation, indexing, retrieval, evaluation, and analysis. The analysis stack uses NumPy, pandas, SciPy, statsmodels, matplotlib, PyYAML, and pytrec-eval~\cite{vangysel2018pytrec_eval}; retrieval uses Pyserini~\cite{lin2021pyserini}, FlagEmbedding, PyTorch, and FAISS~\cite{douze2024faiss}. Preprocessing uses PySastrawi~\cite{sastrawi} for the bundled root dictionary. The experiment matrix fixes seed 42. BM25 jobs are CPU/Lucene runs; BGE-m3 runs were executed in Kaggle GPU sessions with FAISS HNSW and \texttt{efSearch}=1000.

\subsection{Preprocessing pipeline verification}

Before retrieval, preprocessing must pass a 20-entry gate covering single-token false positives (\id{punya}, \id{tanya}, \id{hanya}, \id{Kenya}, \id{Sonya}) and multi-sentence anaphoric cases. This is a regression check, not a linguistic benchmark; Sastrawi dictionary coverage remains a limitation because rare names, technical terms, and some lexicalised forms can still be mishandled.

\subsection{Indexing}

For each of the five preprocessing strategies, two indices are built per the BM25 and BGE-m3 configurations specified in \secref{sec:method}.

\subsection{Rule-based resolver implementation (Strategy 5)}

The Rule-resolved strategy detects \id{-nya} with the same dictionary guard, classifies each occurrence using surface context, and substitutes anaphoric cases with a recent salient noun phrase. It is deterministic, CPU-only, and applied uniformly rather than selectively. Thus Strategy~5 estimates the deployable value of a cheap in-house resolver, not gold or neural coreference.

\subsection{Sensitivity stratification}

Per-query sensitivity scores are computed as
\begin{equation}
\begin{aligned}
\mathrm{sensitivity}(q) ={}& \alpha \, c_{\text{nya}}(q) + \beta \, c_{\text{ana}}(q) \\
&+ \gamma \, \mathbf{1}_{\text{entity via -nya}}
\end{aligned}
\label{eq:sensitivity}
\end{equation}
using total and heuristically-detected anaphoric \id{-nya} counts in gold-relevant passages, plus an indicator for queried-entity reference via \id{-nya}. We use frozen weights $\alpha = 1$, $\beta = 2$, $\gamma = 3$ and stratify queries into low/mid/high tertiles.
