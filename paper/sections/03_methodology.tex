\section{Methodology}
\label{sec:method}

\subsection{Experimental design}

We adopt a within-subjects factorial design with two factors: preprocessing strategy (five levels) and retriever architecture (two levels). Every dev-set query is evaluated under every combination of conditions.

\subsection{Retrievers}

We evaluate two retriever architectures spanning the sparse--dense spectrum.

\smallskip
\noindent\textbf{BM25.} Standard BM25 implementation in Pyserini~\cite{lin2021pyserini}, with $k_1 = 0.9$ and $b = 0.4$ (standard MIRACL configuration). Tokenisation uses the default whitespace-plus-punctuation analyser.

\smallskip
\noindent\textbf{BGE-m3.} The dense embedding mode of BGE-m3~\cite{chen2024bgem3}, with maximum sequence length capped at 512 tokens. Indices built using FAISS~\cite{douze2024faiss} HNSW~\cite{malkov2020hnsw} with $M = 32$ and \texttt{efConstruction} $= 200$.

\subsection{Dataset}

We evaluate on the Indonesian split of MIRACL~\cite{zhang2023miracl}: approximately 1.4 million Wikipedia passages and 960 development-set queries with native-annotated relevance judgments.

\subsection{Metrics}

\noindent\textbf{Primary:} nDCG@10. \textbf{Secondary:} MRR@100, nDCG@1, Recall@10, Recall@100. Per-query metrics are computed under every condition; nDCG@1 is reported as a more sensitive metric in case of saturation effects on dense baselines.

\subsection{Sensitivity stratification}

Per-query \id{-nya} sensitivity scores are computed using the formula
\begin{equation}
\mathrm{sensitivity}(q) = \alpha \, c_{\text{nya}}(q) + \beta \, c_{\text{ana}}(q) + \gamma \, \mathbf{1}[\text{queried entity referenced via -nya}]
\label{eq:sensitivity}
\end{equation}
where $c_{\text{nya}}$ and $c_{\text{ana}}$ are counts of total and heuristically-detected anaphoric \id{-nya} occurrences in the gold-relevant passages, with weights $\alpha = 1$, $\beta = 2$, $\gamma = 3$ (frozen prior to main analysis). Queries are stratified into low/mid/high tertiles for the H5 analysis.

\subsection{Statistical analysis}

Omnibus tests use Friedman's test on per-query nDCG@10. Pairwise post-hoc tests use Wilcoxon signed-rank with Bonferroni correction across the $\binom{5}{2} = 10$ pairs per retriever ($\alpha = 0.005$ within each retriever family). Effect sizes are reported as Cliff's $\delta$. Bootstrap 95\% confidence intervals on $\Delta$nDCG@10 are computed with 10{,}000 resamples. The H5 stratification analysis uses a mixed-effects model with strategy-by-stratum interaction. The protocol follows the recommendations of Dror et al.~\cite{dror2018hitchhiker}.

\subsection{Reproducibility and pre-registration}

This methodology was committed to a public Git repository prior to running any experimental code, serving as a lightweight pre-registration of the design. All code, intermediate indices, and analysis scripts will be released under an open licence on completion.
