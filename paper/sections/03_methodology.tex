\subsection{Experimental design}

We adopt a within-subjects factorial design with two factors: preprocessing strategy (five levels) and retriever architecture (two levels). Every dev-set query is evaluated under every combination of conditions.

\subsection{Retrievers}

We evaluate one sparse and one dense retriever.

\smallskip
\noindent\textbf{BM25.} Pyserini BM25~\cite{lin2021pyserini}, with $k_1 = 0.9$, $b = 0.4$, and top-1000 retrieval.

\smallskip
\noindent\textbf{BGE-m3.} BGE-m3 dense embeddings~\cite{chen2024bgem3} indexed with FAISS~\cite{douze2024faiss} HNSW~\cite{malkov2020hnsw} ($M=32$, \texttt{efConstruction}=200). We set \texttt{max\_length}=512 to match MIRACL passage lengths; BGE-m3 supports up to 8192 tokens, so this truncation is unlikely to affect these passage-level runs.

\subsection{Dataset}

We evaluate on the Indonesian split of MIRACL~\cite{zhang2023miracl}: approximately 1.4 million Wikipedia passages and 960 development-set queries with native-annotated relevance judgments.

\subsection{Metrics}

\noindent\textbf{Primary:} nDCG@10. \textbf{Secondary:} MRR@100, nDCG@1, Recall@10, Recall@100. Per-query metrics are computed under every condition.

\subsection{Sensitivity stratification}

Per-query \id{-nya} sensitivity scores are computed using the formula
\begin{equation}
\begin{aligned}
\mathrm{sensitivity}(q) ={}& \alpha \, c_{\text{nya}}(q) + \beta \, c_{\text{ana}}(q) \\
&+ \gamma \, \mathbf{1}_{\text{entity via -nya}}
\end{aligned}
\label{eq:sensitivity}
\end{equation}
where $c_{\text{nya}}$ and $c_{\text{ana}}$ count total and heuristically-detected anaphoric \id{-nya} occurrences in gold-relevant passages, and the indicator marks whether the queried entity is referenced via \id{-nya}. We use frozen weights $\alpha = 1$, $\beta = 2$, $\gamma = 3$ and split queries into low/mid/high tertiles.

\subsection{Statistical analysis}

Omnibus tests use Friedman's test on per-query nDCG@10. Pairwise post-hoc tests use Wilcoxon signed-rank with Bonferroni correction across 10 pairs per retriever. We report Cliff's $\delta$ and bootstrap 95\% confidence intervals from 10{,}000 resamples, following Dror et al.~\cite{dror2018hitchhiker}. H5 uses within-stratum pairwise Wilcoxon tests by sensitivity tertile, Bonferroni-corrected within each tertile.

\subsection{Reproducibility and pre-registration}

This methodology was committed before the main runs as a lightweight pre-registration. Code, run files, metric CSVs, and analysis scripts are released with the project.
