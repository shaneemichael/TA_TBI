\section{Experiments}
\label{sec:experiments}

\subsection{Implementation}

The experiment is implemented as a Python package with command-line entry points for data preparation, indexing, retrieval, evaluation, and statistical analysis. The dependency specification pins the main analysis stack to Python~$\geq 3.10$, NumPy, pandas, SciPy, statsmodels, matplotlib, PyYAML, and pytrec-eval~\cite{vangysel2018pytrec_eval}. Optional retrieval extras are separated by backend: BM25 uses Pyserini~\cite{lin2021pyserini}~$\geq 0.21$ over Lucene/Anserini, while dense retrieval uses FlagEmbedding~$\geq 1.3$ with PyTorch and FAISS~\cite{douze2024faiss}. Preprocessing uses PySastrawi~\cite{sastrawi}~$\geq 1.2$ for the bundled Indonesian root dictionary used by Strategy~3 and by the Strategy~5 dictionary guard.

The experiment matrix fixes the random seed at 42 and evaluates five preprocessing strategies across two retrievers on MIRACL-id dev. BM25 uses $k_1=0.9$, $b=0.4$, and retrieves the top 1000 documents per query. BGE-m3 uses the \texttt{BAAI/bge-m3} dense encoder and a FAISS \texttt{IndexHNSWFlat} index with $M=32$ and \texttt{efConstruction}=200; the Kaggle dense-run scripts use \texttt{efSearch}=1000 at retrieval time. The dense experiments were run in Kaggle GPU sessions, normally with a single exposed CUDA device; the runbook supports multiple devices when the runtime exposes them. BM25 indexing and retrieval are CPU/Lucene jobs.

\subsection{Preprocessing pipeline verification}

Before full retrieval, the preprocessing pipeline is checked against a 20-entry verification gate: ten single-token canonical cases and ten multi-sentence cases covering anaphoric \id{-nya}, false positives such as \id{punya}, \id{tanya}, \id{hanya}, \id{Kenya}, and \id{Sonya}, and known resolver edge cases. The gate confirms that the dictionary-guarded strategies preserve canonical non-clitic endings while allowing true clitic examples such as \id{rumahnya}, \id{bukunya}, and \id{pidatonya} to be transformed under the stripping conditions.

This verification is not treated as a held-out linguistic benchmark; it is a guard against implementation regressions. The full analysis still reports the Sastrawi dictionary limitation explicitly, because Path~A uses Sastrawi's bundled root list rather than a manually curated exception dictionary. Consequently, some adverbial or lexicalised forms can still be stripped if their apparent root is present in Sastrawi.

\subsection{Indexing}

For each of the five preprocessing strategies, two indices are built per the BM25 and BGE-m3 configurations specified in \secref{sec:method}.

\subsection{Rule-based resolver implementation (Strategy 5)}

The rule-based \id{-nya} anaphora resolver is implemented as a three-stage pipeline: (i)~clitic detection using the same dictionary-guarded matcher as Strategies 3 and 4, (ii)~functional-class classification (possessive, definite, anaphoric, nominaliser) using surface-context heuristics over the host word and sentence context, and (iii)~antecedent substitution for occurrences classified as anaphoric, selecting a recent salient noun phrase from the prior one to two sentences. The resolver is intentionally deterministic and CPU-only. It is applied uniformly to MIRACL-id passages and queries as part of the same preprocessing sweep as the other strategies, rather than selectively on examples where resolution appears beneficial.

The implementation choice is deliberately conservative: Strategy~5 estimates the deployable value of a cheap in-house resolver, not the value of gold coreference labels or a high-capacity neural resolver. This distinction is important for interpreting the negative H4 result in \secref{sec:results}.

\subsection{Sensitivity stratification}

Per-query \id{-nya} sensitivity scores are computed using the formula
\begin{equation}
\mathrm{sensitivity}(q) = \alpha \cdot c_{\text{nya}}(q) + \beta \cdot c_{\text{ana}}(q) + \gamma \cdot \mathbf{1}[\text{queried entity referenced via -nya}]
\label{eq:sensitivity}
\end{equation}
where $c_{\text{nya}}$ and $c_{\text{ana}}$ are counts of total and heuristically-detected anaphoric \id{-nya} occurrences in the gold-relevant passages, with weights $\alpha = 1$, $\beta = 2$, $\gamma = 3$ (frozen prior to main analysis). Queries are stratified into low/mid/high tertiles for the H5 analysis.
